# Student Marks Analyzer

## Overview

This project demonstrates the basics of Pandas by analyzing student marks from a CSV file.

## Features

- Read CSV files
- Explore datasets
- Filter and sort data
- Calculate Total and Average marks
- Assign Grades
- Perform statistical analysis
- Group students by department
- Export processed data

## Technologies

- Python
- Pandas

## Dataset

students.csv

## Output

student_report.csv

## Concepts Learned

- DataFrames
- Series
- loc
- iloc
- Filtering
- Sorting
- GroupBy
- Apply
- Exporting CSV
