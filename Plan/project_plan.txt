GOAL
────
Learn AI, Machine Learning, Deep Learning, Data Science and related
technologies by building small practical projects.

CORE RULE
─────────
One Topic → One Mini Project → Learn the Concepts → Complete → Move On

The objective is not to memorize every library or algorithm first.
Each project is used to understand and implement one concept in practice.

══════════════════════════════════════════════════════════════════════
LEARNING PRINCIPLES
══════════════════════════════════════════════════════════════════════

1. Learn by building.
2. One major topic at a time.
3. Every algorithm gets a practical implementation.
4. Avoid learning libraries without understanding the underlying concept.
5. Reuse previous knowledge in later projects.
6. Keep every project documented on GitHub.
7. Prefer realistic datasets over artificial toy examples when possible.
8. After completing a technology's project series, study the technology
   separately and fill any remaining gaps.
9. Gradually move from notebooks → scripts → applications → deployment.
10. The final projects combine multiple technologies learned earlier.

Each project should preferably contain:

```
project/
├── data/
├── output/
├── notebook.ipynb
├── app.py / script.py

```
