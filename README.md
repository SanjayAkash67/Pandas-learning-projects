# 🐼 Pandas Learning by Projects

A hands-on collection of mini projects designed to master **Pandas** through practical applications instead of isolated theory.

The goal of this repository is to build a strong foundation in data manipulation, cleaning, analysis, and preparation for Machine Learning by completing real-world mini projects.

---

## 📚 Learning Approach

- Learn one concept through one project
- Focus on practical implementation
- Use real or realistic datasets
- Document progress through GitHub
- Build reusable skills for Data Science and Machine Learning

---

## 🛠 Technologies

- Python 3.x
- Pandas
- Jupyter Notebook
