# 🐼 Pandas Learning Projects

A hands-on, project-based repository for learning **Pandas through practical data analysis tasks**.

Instead of learning Pandas only through isolated syntax examples, this repository is organized into **10 practical projects**, progressing from basic DataFrame operations to real-world data analysis workflows.

The projects cover data cleaning, analysis, grouping, merging, pivot tables, time series, text processing, large datasets, Excel processing, and a final e-commerce analysis project.

---

## 📚 Projects

| #  | Project                       | Main Concepts                                                   |
| -- | ----------------------------- | --------------------------------------------------------------- |
| 01 | **Student Marks Analyzer**    | DataFrames, selection, filtering, sorting, basic analysis       |
| 02 | **Data Cleaning**             | Missing values, duplicates, data types, cleaning techniques     |
| 03 | **Sales Data Analysis**       | GroupBy, aggregation, filtering, business analysis              |
| 04 | **Merge & Join**              | Merge, joins, concatenation, combining datasets                 |
| 05 | **Pivot Tables**              | Pivot tables, aggregation, cross-tabulation, reporting          |
| 06 | **Time Series Analysis**      | Datetime, resampling, rolling calculations, time-based analysis |
| 07 | **String Operations**         | Text cleaning, string methods, pattern matching, extraction     |
| 08 | **Large Dataset Analysis**    | Memory usage, data types, chunk processing, optimization        |
| 09 | **Excel Data Processing**     | Reading/writing Excel files, data processing, automated reports |
| 10 | **Final E-Commerce Analysis** | Multi-table analysis, merging, cleaning, business insights      |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SanjayAkash67/Pandas-learning-projects.git
cd Pandas-learning-projects
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux/macOS:**

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Open the notebooks

```bash
jupyter notebook
```

Then open the project you want to study.

## 📊 Final Project — E-Commerce Analysis

The final project uses the **Brazilian Olist e-commerce dataset** to demonstrate a more realistic data analysis workflow.

It combines multiple related datasets such as:

* Customers
* Orders
* Order Items
* Payments
* Products
* Sellers
* Reviews
* Geolocation

The project demonstrates how individual datasets can be cleaned, combined and analyzed to answer business-oriented questions.

> **Note:** This is a real-world historical dataset, not a live real-time data source.

### Dataset

The large Olist dataset is intentionally not required to be included directly in the repository. Follow the instructions inside the final project folder to obtain and place the dataset files locally before running the notebook.

## 💡 How to Use This Repository

For the best learning experience:

1. Start with Project 01.
2. Understand the operations used in each project.
3. Try modifying the examples yourself.
4. Experiment with different filters, groupings and calculations.
5. Move to the next project after understanding the current one.
6. Use the final project to practice combining multiple Pandas techniques.

Don't just run the notebooks — **modify the code and experiment with the data.**
